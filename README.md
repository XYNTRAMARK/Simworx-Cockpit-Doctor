# Simworx Cockpit Doctor

DA62 MobiFlight diagnostics and X-Plane 12 live command test bench.

**Status:** diagnostic software; live command tests operate simulated aircraft systems. Do not use during flight or while anyone is operating the simulator.

Windows: install Python 3, then double-click `START_COCKPIT_DOCTOR.bat`.

This tool does not change your MobiFlight mappings.
